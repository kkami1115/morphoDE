# 界面の出っ張り vs 引っ込みで発現は違うか — 種を越えた検証

## 要旨

「細胞種の異なるドメインの境界(界面)には出っ張った部分と引っ込んだ部分があり、そこで遺伝子発現が違う」という素朴な仮説を、**11データセット・126界面-層(ヒト腫瘍から植物の葉まで)** で検証した。曲率(連続量)は使わず、ラベル付き点群から**真の開いた界面シート**を直接抽出し(両側にサンプルされた組織がある面だけを残し、組織ブロックの物理的切断面を除外)、**密度自適応**の解像度で構築した。出っ張り/引っ込みはシートの**法線変位**による二値ラベルで、符号は面の物理的向きで固定する(正=凸=ドメインが隣接側に突出、負=凹=引っ込み)。**同一細胞種内**に絞って差次発現を測り、**各発生段階・再生時点・検体をそれぞれ独立の界面-層**として実行し、**幾何破壊ヌル**(z帯内の方位角円環シフト、n=200)で有意性を検定した。

結論: **この対応は腫瘍に固有ではなく、種・器官・発生段階・個体を越えてほぼ普遍的に成立する**。全11データセットで信号があり(11/11)、**126界面-層中125**が≥1遺伝子生存、**97**が半数以上(≥6/12)、**16**が満点(12/12)。生存ゼロは1界面-層のみ — これはヌルが正しく働いた例。因果方向(幾何が発現を駆動するのか、発現差が幾何を形づくるのか)はスナップショットからは決定できず、主張しない。

## 背景と設計の要点

この検証は、先行する曲率解析の帰結から動機づけられた。連続的な局所曲率(平均曲率H・ガウス曲率K・shape index)→発現の結合は、空間自己回帰(SAR/GM_Lag)の下でopenst腫瘍でもflysta3d表皮でも消失した。しかし**SARは「発現の空間ラグ(近傍発現そのもの)を超えて幾何が予測力を足すか」という、この素朴仮説には不利すぎる問い**を立てていた — 幾何が発現を駆動するなら、その効果自体が空間的に滑らかでラグ項と共線になり吸収される。

そこで仮説を1段プリミティブに戻し、**粗い二値の凹凸**を問うた。検定も設計も差し替えた:
- **幾何破壊ヌル**: 各z帯で界面重心周りの方位角順に凸凹スコアを並べ、円環シフトする。空間的な滑らかさ(隣接細胞は似たスコア)は保たれ、スコアと実位置の対応だけが壊れる。「幾何ラベルと発現の対応が、空間平滑なランダム再配置より強いか」を直接問う。
- **同一細胞種内**: 対象ドメインの細胞のみでDE。細胞種構成の差(組成交絡)を構造的に除いた内在成分を見る。ヒト腫瘍では、これで差の**93%が単一腫瘍細胞種内**に残る — 組成の入れ替えでなく真に細胞種内の変化。
- **真の開いた界面(閉曲面ではない)**: 初期版はドメインの凸包を使ったが、これは取得組織ブロックを閉じた立体にし、物理的切断面を「出っ張り」と誤ラベルする。定量検証(出っ張り細胞の60μm近傍は非腫瘍わずか~4% — 実境界でなく未サンプル空間に面していた)の上で、両側に組織がある面だけを残す**真の開いた界面シート**に作り直した。シート解像度は**密度自適応**(ボクセル辺長を局所細胞密度に合わせる。データセットごとの手調整なし)。
- **層別化(全層報告)**: 発生アトラスは複数段階・検体を含み、界面幾何が段階/体サイズと交絡する。そこで**各段階・再生時点・検体をそれぞれ独立の界面-層**として実行し全て報告する。特定の層を選ぶ恣意性を排し、主張は生物学的条件を越えて成立する場合のみ立つ。

openst腫瘍界面では、この設計で幾何破壊ヌルを生き延びる差(12/12、うち93%は単一腫瘍細胞種内)が示され、帰無較正(偽陽性名目5%以下)・検出力(lfc=0.02で100%)も実証済みである。出っ張り=凸=腫瘍が間質へ突出、とすると: **出っ張り = IGKC, IGHG3, DHCR7, S100A7, CD74**(免疫グロブリン/抗原提示/コレステロール合成)、**引っ込み = PTHLH, FTH1, KRT17, AMTN, FABP5**(低酸素/浸潤/角化)。本レポートはこの手段を全データセットに適用した結果である。

## 全体像

- **全126界面-層**: ≥1遺伝子生存 **125/126**、半数以上(≥6/12)生存 **97**、満点(12/12)**16**、生存ゼロ **1**。
- **全11データセットで≥1界面が信号あり(11/11)** — ヒト腫瘍、マカク小脳、アホロートル脳、ゼブラフィッシュ胚、マウス胚3種、ハエ幼虫/蛹、プラナリア、シロイヌナズナ葉。
- **信号は条件を越えて再現する — 単発の偶然ではない**。プラナリアは全47界面-層(3体領域×16再生時点)、アホロートルは全20(4領域×5再生段階)、digitalマウス胚は20中19(4胚葉界面×最大6検体)で信号あり。満点(12/12)の16界面-層は系統的に無関係(ヒト腫瘍・マカク小脳・アホロートル・ゼブラフィッシュ・シロイヌナズナ・多数のプラナリア時点)。
- **唯一の生存ゼロ**(digitalマウス胚Paraxial mesoderm、1検体): その差が凸凹でなく他の空間構造(体軸位置)に対応するため幾何破壊ヌルで消える。これこそヌルの働き — 同じ界面が胚の他検体では強い信号を持つ。

## 解釈と限界

**概念は一般的**: 「細胞種境界の凸部と凹部で発現が違う」は腫瘍生物学の話ではなく、上皮・間葉・神経・再生芽・胚葉など多様な界面で成立する一般的な組織構築の性質と見られる。出っ張り/引っ込みは局所的な微小環境(機械的張力、拡散距離、隣接細胞種への露出)を変え、それが細胞状態に反映される、という描像と整合する。

**界面依存性は特徴であって欠陥でない**: すべての界面・全条件で成立するわけではない。幾何破壊ヌルは「凸凹に真に対応する差」と「たまたま別の空間軸に沿った差」を選別し、後者を正しく落とす。

**方法論上の必須条件**:
1. **同一細胞種内**に絞る(さもなくば大半は組成交絡。ヒト腫瘍では絞っても差の93%が残る — 真に細胞種内)。
2. **真の開いた界面**を使う(閉じた凸包は取得ブロックの切断面を出っ張りと誤ラベルする)。
3. **全段階・検体の層を報告**する(発生アトラスでは段階が界面幾何と交絡。全層報告で層の恣意的選択の誘惑を排す)。
4. 界面解像度は**密度自適応**。薄いスラブ(Z切片が少ない)では達成可能な解像度、ひいては感度が制限される。

**因果方向は決定不能**: 単一時点のスナップショットからは、幾何が発現を駆動するのか、発現差が組織を変形させて幾何を作るのかを区別できない。本解析が証明するのは「幾何と発現の対応が、組成・空間平滑構造・場所・発生段階を除いても残る」ことまでである。

## 手法と再現性

- 界面手法は `src/open_interface.py`: `extract_open_interface`(真の開いたシート、密度自適応pitch)、`band_scores`(法線変位、凸=出っ張り)、`de_and_null`(同一細胞種内DE + 幾何破壊ヌル)。スコア算出・分解のヘルパーはスキル `interface-bulge-dent-de` として公開。
- 各データセットは記録した読み込みレシピで処理し、複数段階/検体のデータは全層に展開した。全層でn_perm=200、最近接1/3距離分位数の界面バンドを使用。
- 曲率は使用していない(法線変位ベース、平均曲率での感度チェックあり)。出っ張り/引っ込みの符号は面の物理的向き(凸=ドメインが隣接側に突出)で固定し、シート上の局所ドメイン率で検証した。
